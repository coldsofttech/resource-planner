Employment Types

Classify how team members are engaged — permanent, contractor, part-time, and so on.

Employment Types label the nature of each member's contract. They appear in workforce reports and filters, and can be used to segment capacity assumptions across different categories of worker.

Actions on this page

Button / ActionWhat it does
Add Employment TypeCreate a new type with a clear, descriptive name.
Edit Update the name. Changes apply immediately to all members who hold this type.
Set as DefaultPre-selects this type when creating new members. Only one can be the default at a time.
Deactivate / ActivateHides or shows the type in member profile dropdowns.
Delete Removes the type if no members currently use it.
Import / ExportBulk-create types from a spreadsheet, or download the list.

How to use

  1. Go to Employment Types and click Add Employment Type.
  2. Enter a clear, self-explanatory name (e.g. Full-time Permanent, Fixed-Term Contractor, Part-time).
  3. Mark one as the default — typically your most common employment type.
  4. Click Save. The type now appears in member profile dropdowns.
