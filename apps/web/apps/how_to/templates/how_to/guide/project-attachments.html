Project Attachments

Upload, download, and manage files attached directly to a project — PDFs, spreadsheets, documents, and more.

Project Attachments let you store files directly alongside a project record. Use the Attachments tab to upload supporting documents — a signed-off proposal, a discovery deck, a budget spreadsheet, or any reference file your team needs easy access to. All file types are accepted. Files can be downloaded by anyone with access to the project, and deleted by users with the appropriate permission.

Navigating to Project Attachments

  1. Open any project from the Projects list.
  2. Click the Attachments tab inside the project detail page.
  3. All files attached to this project are listed here, with the most recently uploaded at the top.

Actions on the Attachments tab

Button / ActionWhat it does
Upload zoneClick browse from your computer or drag and drop files onto the zone to queue them for upload. Visible only to users with the upload permission.
Download Downloads the file to your computer. Available to all users who can view the Attachments tab.
Delete Permanently removes the file. A confirmation prompt appears before deletion. Requires the delete attachment permission.

Uploading a file

  1. Open the project and click the Attachments tab.
  2. Click browse from your computer in the upload zone, or drag one or more files directly onto the zone.
  3. Selected files appear as tags below the upload zone. Each tag shows the filename and size. Click the × on any tag to remove a file from the queue before uploading.
  4. Files upload automatically once queued. A success toast confirms each upload and the file appears at the top of the table immediately.
All file types are accepted. There is no restriction on file extension — PDFs, XLSX, Word documents, images, ZIP archives, and any other format can be attached. The file type icon in the table gives a quick visual hint: PDF, spreadsheet (XLSX/XLS), and CSV files each show a distinct icon; all other formats show a generic file icon.

Uploading multiple files at once

  1. In the file picker, select multiple files using Ctrl+click (Windows) or Cmd+click (Mac), or drag a batch of files onto the upload zone.
  2. Each file appears as a separate tag. Remove any you do not want to upload by clicking its × button.
  3. All queued files upload in sequence. Each creates a separate attachment record with its own download link.

Downloading a file

  1. On the Attachments tab, click the Download action on the row you want.
  2. The file downloads to your computer using the original filename. No page navigation occurs.

Deleting a file

  1. On the Attachments tab, click the Delete action on the file you want to remove.
  2. Confirm the deletion in the prompt that appears.
  3. The file is permanently removed from the project and from storage. This action cannot be undone.

Attachment table columns

ColumnWhat it shows
IconA visual indicator of the file type — PDF, spreadsheet, CSV, or generic.
File NameThe original name of the uploaded file. Click the column header to sort alphabetically.
TypeThe file's MIME type (e.g. application/pdf). Sortable.
SizeThe file size in human-readable units (KB or MB). Sortable.
Uploaded ByThe name of the user who uploaded the file.

File size limit

Individual files must be 25 MB or smaller. Files exceeding this limit are rejected at upload and an error message is shown. There is no limit on the total number of attachments per project.

Who can upload and delete

ActionPermission required
View the Attachments tab and download filesStandard project view access
Upload filesAdd attachment permission (projects.add_projectattachment)
Delete filesDelete attachment permission (projects.delete_projectattachment)
Deletion is permanent. Deleted attachments cannot be recovered. The file is removed from storage immediately. If you need to keep a file but want to replace it, upload the new version first, then delete the old one.
Common errors
"A file with this name already exists on this project" — each filename must be unique within the project. Rename the file before uploading, or delete the existing attachment first if you want to replace it.

"File exceeds the maximum size of 25 MB" — compress or split the file before uploading. For large documents, consider linking to an external location (e.g. SharePoint or Google Drive) using Project Links instead.

"No file uploaded" — the upload request arrived without a file. Try selecting the file again and re-uploading.

"You do not have permission to upload attachments" — contact your administrator to request the Add attachment permission.
Tip: For files too large to attach (over 25 MB), store them in SharePoint, Google Drive, or Confluence and add the link to the project using Project Links. Use Attachments for files that need to travel with the project record — signed documents, final deliverables, meeting minutes — and Links for living documents that are updated frequently in external tools.
