Project Contacts

Record the key external or internal stakeholders associated with a project — delivery contacts, finance contacts, and more.

Project Contacts let you attach named individuals to a project in a specific role. Use them to record who the business stakeholders are — who is accountable for delivery decisions and who holds the financial sign-off — without requiring them to have a Resource Planner account. Contacts are drawn from a shared contact library; adding a new name to a project automatically adds it to that library for reuse on future projects.

Navigating to Project Contacts

  1. Open any project from the Projects list.
  2. Click the Contacts tab inside the project detail page.
  3. All contacts currently assigned to this project are listed here, sorted by name.

Contact roles

RoleIntended for
Project The primary delivery stakeholder — the business sponsor, product owner, or senior responsible owner who is accountable for what the project delivers.
Finance The financial contact — the budget holder, finance business partner, or cost centre owner who approves and monitors project spend.

Actions on the Contacts tab

Button / ActionWhat it does
Add ContactOpens a panel to enter the contact's name, optional email, and role. Saves the contact to the shared library if they are not already in it.
Remove Removes the contact from this project. The contact record remains in the shared library and can be reused on other projects.

Adding a contact

  1. Open the project and click the Contacts tab.
  2. Click Add Contact.
  3. Enter the contact's Name. This field is required.
  4. Optionally enter their Email address.
  5. Select the Role — choose Project for the delivery stakeholder or Finance for the budget holder.
  6. Click Save. The contact is assigned to the project immediately.
Contacts are shared across projects. When you add a contact by name and email, the system checks the shared contact library first. If a contact with the same name and email already exists, it is linked to this project rather than created again. This means the same person can be a stakeholder on multiple projects without duplicating their record.

Removing a contact

  1. On the Contacts tab, click the Remove action next to the contact you want to unlink.
  2. Confirm the removal. The contact is removed from this project only — their record in the shared contact library is preserved, and they remain linked to any other projects they are assigned to.

Permissions

ActionPermission required
View contacts on a projectStandard project view access (projects.view_projectcontact)
Add a contact to a projectAdd project contact (projects.add_projectcontact)
Remove a contact from a projectDelete project contact (projects.delete_projectcontact)
Each contact can only be assigned once per project. The same person cannot be added to the same project twice, even with a different role. If you need to change a contact's role, remove them and re-add them with the correct role.
Common errors
"Contact is already assigned to this project" — this person is already listed on the Contacts tab. Each contact can appear on a project only once. If their role needs updating, remove the existing entry and add them again with the correct role.

"Name is required" — the contact's name cannot be blank. Email is optional, but a name is always required to identify the contact.

"You do not have permission to add contacts" — contact your administrator to request the Add project contact permission.
Tip: Add contacts at project creation time so that stakeholders are always visible alongside the project record. Including an email address makes it easier for team members to reach the right person directly from the project page — especially useful for Finance contacts during budget review cycles.
