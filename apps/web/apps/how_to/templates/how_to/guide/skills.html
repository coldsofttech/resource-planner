Skills

A shared library of competencies assigned to team members for resource matching.

Skills define the competencies in your workforce. Members can hold multiple skills. Skill data powers workforce search and resource planning filters — helping you find people with the right expertise for a given project.

Actions on this page

Button / ActionWhat it does
Add SkillCreate a new skill with a short name (max 20 characters) and optional description.
Edit Update the name or description. Changes appear immediately on all member profiles that hold this skill.
Deactivate / ActivateHides the skill from the member profile dropdown. Members who already have it keep it on their profile.
Delete Removes the skill from the library permanently. Only possible when no members currently hold it.
Import / ExportBulk-create skills from a spreadsheet, or download the skill library.

How to use

  1. Go to Skills and click Add Skill.
  2. Enter a short, precise name — 20 characters maximum. Use the simplest recognisable form (e.g. Python, not Python programming language).
  3. Add an optional description if the name needs clarification and click Save.
  4. Assign skills to members via their Profile → Workforce tab.
Common errors
"Cannot delete a skill assigned to members" — deactivate the skill instead. It will be hidden from the dropdown but will remain visible on existing member profiles. To fully delete it, first remove it from all affected profiles.
Tip: Agree on a fixed skill vocabulary before building the library. Having AWS, Amazon Web Services, and aws-cloud as three separate entries makes skill-based filtering useless. One canonical name per skill, consistently applied.
