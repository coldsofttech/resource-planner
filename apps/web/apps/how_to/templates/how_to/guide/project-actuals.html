Project Actuals

Track cumulative spend against the approved estimate — by financial year and by sprint.

Project Actuals show how much has been spent on a project relative to its approved estimate, broken down by financial year and sprint. The Actuals tab gives the team an immediate view of where the project stands financially — how much has been consumed, how much remains, and whether the project is on track or at risk of overspend.

Navigating to Project Actuals

  1. Open any project from the Projects list.
  2. Click the Actuals tab inside the project detail page.
  3. The tab shows summary cards at the top, a breakdown table below, and a gear icon (⚙) in the panel header to open the config drawer.

Summary cards

Four cards appear at the top of the Actuals tab.

CardWhat it shows
Approved EstimateTotal cost from the current approved estimate (days × day rate).
Contingency BudgetApproved estimate plus the configured contingency percentage.
Total ActualsCumulative spend to date — current financial year plus all prior-year carry-forward.
Remaining AmountBudget remaining. A negative value indicates overspend beyond the contingency budget.

A risk badge appears alongside the Remaining Amount when spend has exceeded the approved estimate base cost:

BadgeColourMeaning
Warning AMBER Spend is above the base estimate but still within the contingency budget.
At Risk RED Spend has exceeded the contingency budget. Immediate attention required.
The risk badge is hidden when: there is no approved estimate linked to the project, the total actuals are zero, or the Ignore Risk config option is enabled.

Breakdown table — Financial Year view

The default view shows one row per financial year in which the project has recorded actuals.

ColumnDescription
Financial YearThe FY label — for example FY2024-25.
Total DaysWorking days recorded against this project in the financial year.
Total CostSpend for this financial year only — does not include prior years.
Cumulative CostTotal spend from project start through the end of this financial year.

Click any row to drill down into the sprint breakdown for that year.

Breakdown table — Sprint view

Selecting a financial year switches the table to show one row per sprint within that year.

ColumnDescription
SprintThe sprint name.
Sprint No.Sprint number within the financial year.
Total DaysWorking days recorded in this sprint.
Total CostSpend recorded in this sprint.
Cumulative CostRunning total from the first sprint of the financial year through this sprint.
  • Zero-fill — sprints with no actuals for this project are still shown with zero days and cost. The cumulative cost carries forward unchanged across those zero-actuals sprints.
  • Future sprints excluded — only sprints that have started or completed appear in the table. Upcoming sprints are not shown.

Actuals config drawer

Click the gear icon (⚙) in the Actuals panel header to open the config drawer. These settings adjust how actuals are displayed for this project without changing the underlying data.

SettingWhat it does
Ignore Risk When enabled, the risk badge (Warning / At Risk) is hidden regardless of how much has been spent against the estimate. Use this when the estimate no longer reflects current scope but has not yet been formally updated, or when the project team has accepted the overspend.
Ignore Prev FY Actuals When enabled, only the current financial year's spend is included in the Total Actuals card and in risk calculations. Prior-year carry-forward is excluded. Use this when prior-year spend relates to a different contract, team, or funding source and should not count against the current estimate.
Notes A free-text field for recording the reason for any config overrides. Visible only inside this drawer.

Permissions

Actuals data is system-managed. Sprint actuals are imported via the Sprint Actuals import on the Sprints page — they are not entered manually on the project. The Actuals tab displays the imported data; editing the underlying figures is done through the sprint actuals import flow.
Common issues
"No actuals data shown" — actuals have not been imported for this project yet. Use the Sprint Actuals import on the Sprints page to load cost and day figures.

"Remaining Amount shows as N/A" — no approved estimate is linked to this project. Create and approve an estimate to enable remaining amount and risk calculations.

"Risk badge not disappearing after enabling Ignore Risk" — open the config drawer (gear icon) and confirm the setting was saved. The badge should disappear immediately after the config is saved.
Tip: Review the Actuals tab at the end of each sprint to keep a close eye on cumulative spend. Use the Ignore Prev FY Actuals config option to isolate current-year spend when a project carries over across multiple financial years with different funding arrangements.
