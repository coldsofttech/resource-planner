Project Budgets

Track allocated, refined, and remaining budget per financial year — with automatic risk status based on your estimate.

Project Budgets let you record and track financial budgets for each project on a per-financial-year basis. Each budget record captures the approved allocation, an optional refined figure, and links to an estimate version so the remaining budget and risk status can be calculated automatically. One budget record is allowed per project per financial year.

Navigating to Project Budgets

  1. Open any project from the Projects list.
  2. Click the Budgets tab inside the project detail page.
  3. All budget records for this project are listed here, one per financial year.

Budget fields

FieldDescription
Financial Year The financial year this budget applies to. Each project can have at most one budget record per financial year.
Allocated Budget The initial approved budget for this project in the chosen financial year. Always required.
Refined Budget An optional revised budget figure. When set, this replaces the Allocated Budget as the actual budget used for remaining budget and risk calculations. Use this when the approved amount is revised mid-year without wanting to overwrite the original allocation.
Actual Budget Read-only. The effective budget — the Refined Budget if one is set, otherwise the Allocated Budget.
Estimate Version Optional. Link a saved estimate version to this budget record. When linked, the estimate's total cost is used to calculate the Remaining Budget and Risk Status automatically.
Remaining Budget Read-only. Actual Budget minus the linked estimate's total cost. Only shown when an Estimate Version is linked.
Note Optional free-text field for recording context about this budget record — approval references, revision rationale, or planning notes.

Adding a budget record

  1. Open the project and click the Budgets tab.
  2. Click Add Budget.
  3. Select the Financial Year this budget covers.
  4. Enter the Allocated Budget — the approved amount for this financial year.
  5. Optionally enter a Refined Budget if the original allocation has been revised.
  6. Optionally link an Estimate Version to enable automatic remaining budget and risk status calculation.
  7. Add a Note if needed and click Save.

Editing a budget record

  1. On the Budgets tab, click the Edit action on the record you want to change.
  2. Update the fields as needed and click Save.
  3. Every change is automatically recorded in the budget's history log — you can always see what was changed, when, and by whom.

Budget risk status

When an Estimate Version is linked, Resource Planner calculates a risk status by comparing the estimate's total cost against the Actual Budget. The variance percentage determines the colour-coded risk level.

StatusColourMeaning
On Budget GREEN The cost variance is within the acceptable range for this project's size. The project is tracking on budget.
At Risk (Over) AMBER The estimate exceeds the actual budget, but the overspend is within the configured risk threshold. Monitor closely.
At Risk (Under) AMBER The estimate is below the actual budget within the risk threshold — the project may be under-utilising its allocation.
Over Budget RED The estimate cost exceeds the actual budget beyond the configured threshold. Immediate attention required.
Under Budget RED The estimate cost is significantly below the actual budget beyond the threshold — a large underspend that may indicate planning issues.
Risk thresholds are configurable. The AMBER/RED boundary is set by the Budget Risk Threshold configuration. The GREEN/AMBER boundary is set per project size (XS, S, M, L, XL) using size-specific budget variance settings. Contact your administrator to adjust these thresholds under Settings → Projects.

Lifetime summary

The Lifetime view aggregates budget figures across all financial years for the project. It gives a single rolled-up picture of total allocated budget, total refined budget, total estimate cost, and total remaining budget over the life of the project. Access it from the Budgets tab by clicking Lifetime Summary.

Budget history

Every change to a budget record — an allocation update, a refined budget entry, a linked estimate change — is automatically recorded in the budget's history log. Click the History action on any budget record to see the full audit trail: what changed, the previous and new values, the total cost at the time, and who made the change.

Exporting budgets

Click Export on the Budgets tab to download the budget records for this project. Choose which columns to include — allocated budget, refined budget, actual budget, remaining budget, estimate version, and more. The export respects your current filter selection.

Common errors
"A budget for this financial year already exists on this project" — edit the existing record instead of creating a new one. Use Refined Budget to record a revision without losing the original allocated figure.

"No risk status shown" — risk status only appears when an Estimate Version is linked and both the actual budget and the estimate's total cost are non-zero. Link an estimate version to enable automatic risk calculation.

"Remaining budget shows as the full actual budget" — no estimate version is linked. The remaining budget defaults to the actual budget when no estimate is attached. Link an estimate version to get an accurate remaining figure.
Tip: Create budget records at the start of each financial year before planning begins. Link the most relevant estimate version as soon as one is finalised — this activates automatic risk tracking and gives the team an immediate view of where the project stands financially without any manual calculation.
