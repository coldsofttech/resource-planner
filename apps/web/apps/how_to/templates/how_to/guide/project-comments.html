Project Comments

Leave threaded notes on a project — pin the most important ones to the top so they are always visible.

Project Comments give the delivery team a place to record decisions, flag blockers, or leave context notes directly on the project record. Comments are visible to everyone with access to the project. You can mention specific team members to draw their attention, edit your comment if the situation changes, and pin the most important comment to keep it at the top of the list.

Navigating to Project Comments

  1. Open any project from the Projects list.
  2. Click the Comments tab inside the project detail page.
  3. Comments are shown newest-first, with any pinned comment always at the top.

Actions on the Comments tab

Button / ActionWhat it does
Add CommentOpens the comment input. Enter your text, optionally mention team members, and submit.
Edit Updates the comment text and/or mentions. The comment is marked as edited after saving.
PinMoves the comment to the top of the list so it stays visible regardless of when it was posted. Only one comment can be pinned at a time per project.
UnpinReturns a pinned comment to its natural position in the list (sorted by date).
Delete Permanently removes the comment and any mentions it contained.

Adding a comment

  1. Open the project and click the Comments tab.
  2. Click Add Comment.
  3. Type your comment in the text field.
  4. Optionally mention one or more team members — type their name in the Mentions field and select from the suggestions. Mentioned users receive a notification.
  5. Click Save. Your comment appears at the top of the list.

Editing a comment

  1. On the Comments tab, click the Edit action on the comment you want to update.
  2. Modify the text and/or update the mentions list.
  3. Click Save. The comment is updated and marked as edited so other team members can see it was revised.

Pinning a comment

Pinning keeps one comment permanently visible at the top of the list — useful for decisions, blockers, or context that every team member needs to see when they open the project.

  1. On the Comments tab, click Pin on the comment you want to highlight.
  2. The comment moves to the top of the list and displays a pinned indicator.
  3. To pin a different comment, first Unpin the current one, then pin the new one — or pin the new one directly and the previous pin is replaced.

Comment ordering

Comments are sorted in two tiers:

  • The pinned comment (if any) always appears first.
  • All remaining comments appear below it, ordered newest first.

Mentions

Use mentions to notify specific team members about a comment. Mentioned users are listed on the comment and receive a notification. Mentions can be added when creating a comment and updated when editing one. Each user can only be mentioned once per comment.

Permissions

ActionPermission required
View commentsStandard project view access (projects.view_projectcomment)
Add a commentAdd project comment (projects.add_projectcomment)
Edit, pin, or unpin a commentChange project comment (projects.change_projectcomment)
Delete a commentDelete project comment (projects.delete_projectcomment)
Deletion is permanent. Deleting a comment removes it and all its mentions immediately. There is no undo. If you need to correct a comment rather than remove it, use Edit instead — the comment is updated in place and marked as edited for transparency.
Common errors
"Comment text is required" — a comment cannot be blank. Enter at least one character before saving.

"You do not have permission to edit comments" — editing, pinning, and unpinning all require the Change project comment permission. Contact your administrator to request access.

"You do not have permission to delete comments" — contact your administrator to request the Delete project comment permission.
Tip: Use the Pin feature for the single most important piece of information at any given time — a key decision, an open blocker, or a handover note. Change what is pinned as the project evolves. It is the first thing anyone sees when they open the Comments tab, so keep it current and actionable.
