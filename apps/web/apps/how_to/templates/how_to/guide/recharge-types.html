Recharge Types

Classify the nature of work for financial recharging purposes and link each type to applicable project types.

Recharge types define the categories of work that are recharged to cost centres or budgets — for example BAU (Business as Usual), PROJECT, or HOLIDAY. Each recharge type can be mapped to one or more project types, so the system knows which financial category applies when a project of that type is recharged.

Recharge Types vs. Project Types
Project Types describe what a project is (e.g. Internal, External, Regulatory). Recharge Types describe how the work is funded or recovered (e.g. BAU, PROJECT, OVERHEAD). Mappings link the two so the correct recharge category is applied automatically.

Recharge type fields

NameYesUPPER_SNAKE_CASE only — uppercase letters, digits, and underscores. Must start with a letter. Max 50 characters. Examples: BAU, HOLIDAY_PROJECTS, PROJECT123.
DescriptionNoOptional free-text description. Defaults to empty.
ActiveNoDefaults to Yes. Only active recharge types appear in dropdowns and options.

How to add a recharge type

  1. Go to Recharge Types and click Add Recharge Type.
  2. Enter a name in UPPER_SNAKE_CASE — for example BAU or HOLIDAY_PROJECTS. Names must be unique across all recharge types.
  3. Optionally add a description and confirm the active status.
  4. Click Save. The new recharge type is assigned a system code (RECHTY-{n}) and is immediately available for project type mapping.

Project type mappings

Each recharge type can be linked to one or more project types. Mappings are managed from the recharge type detail view and define which financial category applies when a project of that type is recharged. A project type can only appear once per recharge type — duplicates are rejected.

ActionWhat it does
Add MappingLinks a project type (by code) to this recharge type. Duplicate mappings are rejected with a conflict error.
Remove Mapping Unlinks the project type from this recharge type. The project type itself is not deleted.
Import MappingsUpload a CSV with a project_type_code column to bulk-add mappings. Duplicate or non-existent codes are skipped and reported.
Export MappingsDownload the current mappings for this recharge type as a spreadsheet.

Common errors

  • Name must be UPPER_SNAKE_CASE — Lowercase letters, spaces, hyphens, and leading digits are not allowed. Use BAU, not bau, Bau, or 1BAU.
  • Name exceeds 50 characters — Shorten the name to 50 characters or fewer.
  • A recharge type with this name already exists — Names are unique. Choose a different name or reactivate the existing inactive type instead.
  • Mapping already exists — A project type can only be mapped once per recharge type. The existing mapping must be removed before it can be re-added.
  • Project type not found — The project type code does not exist. Verify the code in the Project Types list and try again.
Tip: Keep names short and stable — they appear in exports and financial reports. Common conventions: BAU for run-the-business work, PROJECT for funded change, OVERHEAD for non-rechargeables, and HOLIDAY for leave cover. Agree on the vocabulary with your finance team before creating the library.
