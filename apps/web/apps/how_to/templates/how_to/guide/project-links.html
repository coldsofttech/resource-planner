Project Links

Attach named URLs to a project — Confluence pages, Jira boards, SharePoint sites, or any external reference.

Project Links let you attach named URLs directly to a project record. Use them to surface the resources your team refers to most — a Confluence planning page, a Jira board, a SharePoint folder, a Miro board, or any external URL. Links appear on the project's Links tab and open in a new browser tab when clicked.

Navigating to Project Links

  1. Open any project from the Projects list.
  2. Click the Links tab inside the project detail page.
  3. All links for this project are listed here, ordered alphabetically by title.

Actions on the Links tab

Button / ActionWhat it does
Add LinkOpens a form to create a new link. Enter a title and a URL.
Edit Update the link's title or URL.
Delete Permanently removes the link. A confirmation prompt appears before deletion.
Click a link titleOpens the URL in a new browser tab.

Adding a link

  1. Open the project and click the Links tab.
  2. Click Add Link.
  3. Enter a Title — a short, descriptive label (e.g. Confluence Planning Page, Jira Board). Titles must be unique within the project.
  4. Enter the full URL — must start with http:// or https://.
  5. Click Save. The link appears in the list immediately, sorted alphabetically.

Editing a link

  1. On the Links tab, click Edit on the link you want to change.
  2. Update the Title and/or URL as needed.
  3. Click Save. The list updates immediately.

Deleting a link

  1. On the Links tab, click Delete on the link you want to remove.
  2. Confirm the deletion in the prompt that appears.
  3. The link is permanently removed. This action cannot be undone.

Link fields

FieldDetails
TitleRequired. A short label for the link. Maximum 200 characters. Must be unique within the project — two links on the same project cannot share the same title.
URLRequired. A full URL beginning with http:// or https://. Maximum 500 characters.
Links open in a new tab. Clicking a link title always opens the URL in a new browser tab. You do not leave the project page.
Link titles must be unique per project. Two links on the same project cannot share the same title. If you need to point to two different URLs with similar names, use a distinguishing qualifier — for example Confluence Planning Page (v1) and Confluence Planning Page (v2).
Common errors
"A link with this title already exists on this project" — each link title must be unique within the project. Choose a different title or update the existing link instead.

"Enter a valid URL" — the URL field only accepts full addresses starting with http:// or https://. Relative paths, bare domain names (e.g. example.com), or mailto addresses are not accepted.
Tip: Use descriptive titles so that anyone opening the project immediately understands what each link points to. "Confluence" tells you nothing; "Confluence — Delivery Planning Page Q3" tells you exactly where to go and why.
